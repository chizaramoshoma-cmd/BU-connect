## 1. Executive Summary

The Student Task & Academic Planner (STAP) is a web-based application designed to help students manage their academic activities, organise assignments, track deadlines and plan study schedules. The application aims to provide a centralised platform that simplifies academic organisation and improves productivity.

The system will allow students to create tasks, manage courses, monitor deadlines and track completed activities through an intuitive dashboard. By combining essential academic planning tools into one platform, STAP seeks to make managing academic responsibilities easier and more efficient.

The project will be developed using modern web technologies and managed through GitHub for version control, documentation and collaboration.

---

## 2. Background / Introduction

Students in tertiary institutions often manage multiple courses, assignments, tests, projects and examinations simultaneously. Keeping track of these responsibilities can become challenging, particularly when deadlines overlap.

Some students rely on handwritten notes, calendars or different applications to manage their academic activities. However, these approaches may not provide a unified system for monitoring progress and organising tasks.

The Student Task & Academic Planner is proposed as a digital solution that enables students to manage their academic responsibilities in one location. The application will provide tools for organising courses, creating tasks, tracking deadlines and planning study activities.

---

## 3. Problem Statement / Needs Assessment

Students may experience difficulties organising academic responsibilities due to the absence of a centralised task management system.

These challenges include:

- Forgetting assignment deadlines.
- Difficulty prioritising academic activities.
- Poor organisation of coursework.
- Inefficient study planning.
- Difficulty monitoring completed and pending tasks.

These challenges can negatively affect productivity, organisation and academic preparation. Therefore, there is a need for a simple digital platform that enables students to manage academic tasks and deadlines more effectively.

## 5. Proposed Solution / Project Description

The proposed solution is a web-based application called Student Task & Academic Planner (STAP).

The application will provide students with a centralised dashboard for managing academic activities and monitoring their progress.

### Proposed Features

#### 5.1 Dashboard

The dashboard will display an overview of academic activities, including total tasks, completed tasks, pending tasks and upcoming deadlines.

#### 5.2 Course Management

Users will be able to add, edit, view and delete courses.

#### 5.3 Task Management

Users will be able to create academic tasks, provide descriptions, assign tasks to courses, set deadlines and update task status.

#### 5.4 Deadline Tracking

The system will display upcoming deadlines and organise tasks according to their due dates.

#### 5.5 Task Prioritisation

Users will be able to assign priority levels to tasks to help organise their workload.

#### 5.6 Progress Tracking

Users will be able to monitor their progress by identifying completed and pending academic activities.

#### 5.7 Responsive Design

The application will be designed to support desktop, tablet and mobile devices.
